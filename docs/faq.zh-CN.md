# 常见问题

> English version: [faq.md](faq.md)

## 会不会封号？

**不知道，也不能保证。** 工具只做和游戏客户端一样的事：带凭据调服务器接口。
没有改包、没有注入、没有模拟点击。但「自动化 / 第三方工具」本身就可能违反
服务条款。**请只在愿意失去的账号上使用**，不要用于排名，不要商用。

## 需要 root 吗？

不需要。也不需要模拟器、不需要装 XP 框架。只要 USB 调试。

## 每次都要点「刷新」吗？

游戏**每次重新登录**都会换凭据，所以是的：重进游戏之后点一次「刷新」。
工具会先把手机里的新凭据拉出来，再读名片。没插手机时也能点，那时候只用现有的
`cred.json` 读。

## 提示「凭据失效 / TOKEN_ILLEGAL」

游戏重新登录过了，旧的 `_authorizationKey` 作废。
插上手机、确认 USB 调试 → 点「刷新」。凭据会自动更新。

## 提示「查无此人 / PLAYER_NOT_EXISTS」

不是凭据问题，是**区服不对**。工具会自动把三个区服挨个试一遍
（港台 / EN / 韩服），谁认这个号就用谁，并把结果记下来。
如果三个都不认，把界面下方的日志发到群里 —— 那说明有新节点还没收录。

## 提示「CONCURRENT_DEVICE」/ 用着用着掉线

游戏和工具同时在线会互相挤。**用工具前先把游戏完全退出。**

## 导入后片上的缩略图不对 / 是空白

正常。缩略图是服务器渲染的，写入后要等游戏客户端下次同步 / 保存才会重画。
名片本体（`body`）从写入那一刻就是对的，进游戏里看就是对的。

## 支持 iOS / 模拟器 / 其他区服吗？

只支持 **Windows + 安卓真机**。iOS 没测试，模拟器没测试。
区服：港台 / EN / 韩服都支持（自动识别）。

## 我的名片会被上传到什么地方吗？

不会。工具只在你电脑和游戏服务器之间通信，没有第三方服务器。
`cred.json` 是**你账号的钥匙**，就在 exe 旁边 —— **别发给任何人**。

## 为什么只有 exe，没有源码？

这个仓库只放文档、时间存证和成品下载。源码不公开，也不授权再分发。
发布包本身是完整的，不需要从源码构建。

## 能一次导入整个 SET / 多个 SET 吗？

界面一次处理一个对象（防止误操作）。命令行版支持整槽 / 多槽导入，
但目前没有随发布包提供；需要的话在群里说。

## 为什么界面长得像另一个工具？

外壳（深色、品牌卡、动效）来自我们另一个工具「谛听 1.0」；
结构和操作方式（左 SET / 右 3×3 仓库）是名片助手一直以来的样子。
